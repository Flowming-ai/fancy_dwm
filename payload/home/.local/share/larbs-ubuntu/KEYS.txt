The system tray stays on the rightmost monitor. Super+b hides/restores that monitor's bar and tray.
Clickable status items: load/memory → btop; volume → pulsemixer; network → nmtui;
input method → Fcitx5 settings; time → calendar; ? → this guide.
st: Ctrl+Shift+c/v to copy/paste; Alt+j/k to scroll; Ctrl+Shift+PageUp/Down to zoom.
Background opacity: Kitty 0.85; st 0.90. Font: JetBrainsMono Nerd Font.
Zsh / Starship / plugins: ~/.config/dwm-shell/zshrc; personal overrides: ~/.zshrc.local.
Pinyin supports local full-sentence input, seven candidates and word-frequency learning.
Cloud Pinyin is disabled by default on a fresh installation.
Default display scale: 150% (Xft DPI). Change it with --scale 100/125/150/175/200 during installation.
Use Alt+d to find Microsoft Teams. It opens an app window in an installed Chrome/Edge/Chromium browser.
If none is available, the launcher shows a notice and opens a regular Firefox/default-browser window.

Configuration source: ~/.local/src/larbs-ubuntu/{dwm,st,dmenu,dwmblocks}
Installation logs/backups: ~/.local/state/larbs-ubuntu/
Close this guide: q
